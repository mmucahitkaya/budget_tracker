Photos, screenshots or PDFs. Text PDFs are parsed line by line and reconciled to the statement total; images are read by a vision model running on your own computer.

Cards and installments

Every card's balance, statement and due date. Installment purchases show up month by month — never twice, even across statements.

Private by design

Your financial data stays in your home.

  • Data lives in a SQLite database inside the add-on and is included in Home Assistant backups.
  • Documents are read by Ollama on a computer on your network — no cloud AI, no API keys.
  • Sign-in is your Home Assistant account; you choose which users may open the app.
  • The only outside calls are for exchange rates and investment prices.

Install in a few minutes

Requires Home Assistant OS or Supervised (add-ons). Document reading is optional and needs a computer that can run Ollama — an Apple Silicon Mac or a PC with a GPU works well.

＋ Add repository to Home Assistant

Add the repository

Settings → Add-ons → Add-on store → ⋮ → Repositories, then add https://github.com/mmucahitkaya/budget_tracker.

Install “Budget Tracker”

Start it and turn on “Show in sidebar”. It opens as a panel in Home Assistant and in the companion app.

Answer the setup questions

Currency, number format and optional extras. You can change them any time in More → Settings.

Optional: local document reading

Install Ollama, run ollama pull qwen3-vl:8b-instruct, start it with OLLAMA_HOST=0.0.0.0 and set the URL in the add-on options.

FAQ

Which banks are supported?

Any bank. Text PDFs are parsed with rules that understand US (1,234.56) and European (1.234,56) number formats and common installment notations; anything else goes to the local vision model. You always confirm a statement before it is saved.

Which currencies?

Pick a base currency at setup (USD, EUR, GBP, TRY and more). Transactions can be in other currencies too and are converted with daily European Central Bank rates.

Can two people use it?

Yes — it is built for a household. Each Home Assistant user signs in as themselves; cards, salaries and spending can belong to either person or be shared.

Does it work without the AI model?

Yes. Everything works with manual entry and the Telegram bot; the model only reads receipts and statements.
